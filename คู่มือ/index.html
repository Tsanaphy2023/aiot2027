3 ขั้นตอนการติดตั้งและนำเข้า Appliance
1
ติดตั้ง VirtualBox

เปิดไฟล์ตัวติดตั้งที่ดาวน์โหลดมา กด Next หรือ Yes ตามขั้นตอนมาตรฐานจนเสร็จสมบูรณ์

2
นำเข้าไฟล์ Appliance (.ova)

เปิด VirtualBox → ไปที่เมนู File → เลือก Import Appliance...

3
เลือกไฟล์และยืนยัน

คลิกปุ่มเบราว์เซอร์เลือกไฟล์ .ova ที่ดาวน์โหลดไว้ → กด Next → ค่าต่าง ๆ ถูกตั้งค่ามาพร้อมใช้แล้ว กด Finish (หรือ Import) แล้วรอแถบทำงานจนเสร็จ 100%

4 การเปิดเครื่องและตรวจสอบความพร้อม (First Boot)
⚠️
ข้อควรระวังสำคัญที่สุด: ต้องเชื่อมต่อแล็ปท็อปเข้ากับเครือข่าย Wi-Fi ให้เรียบร้อย ก่อน ที่จะกดเปิดเครื่องเสมือนทุกครั้ง เพื่อให้เครื่องเสมือนได้รับหมายเลข IP
  1. คลิกเลือกเครื่อง Farm Workshop ในหน้าต่าง VirtualBox
  2. กดปุ่ม Start (ลูกศรสีเขียว) แล้วรอเครื่องบูตประมาณ 2–5 นาที
  3. เมื่อหน้าต่างจอดำแสดงขึ้น ให้สังเกตบรรทัด IPv4 addresses:
Farm Workshop Console
Welcome to Farm Workshop (Home Assistant OS)
IPv4 addresses for enp0s3: 192.168.1.50/24   (Windows / Mac Intel)
IPv4 addresses for enp0s8: 192.168.1.50/24   (Mac Apple Silicon)
URL: http://192.168.1.50:8123 หรือ http://192.168.1.50
🎯
ทดสอบเปิดหน้าควบคุม: เปิดเว็บเบราว์เซอร์แล้วพิมพ์ http://<เลข IP ของท่าน> (เช่น http://192.168.1.50)
หากเห็นหน้า Login ของ Home Assistant แสดงว่าเครื่องของท่านพร้อมสำหรับการอบรมแล้ว! (ยังไม่ต้องเข้าระบบ วิทยากรจะแจ้งชื่อผู้ใช้และรหัสผ่านในวันอบรม)
🚫
ห้ามใช้งานผ่าน homeassistant.local: ในห้องอบรมทุกคนจะอยู่ในเครือข่ายเดียวกัน หากใช้ชื่อนี้ระบบจะชนกัน ให้จดจำและเข้าใช้งานด้วยหมายเลข IP ตัวเลขเสมอ
5 การปิดเครื่องเสมือนอย่างปลอดภัย (Safe Shutdown)

เมื่อทดสอบเสร็จเรียบร้อยแล้ว ให้ปิดเครื่องตามขั้นตอนดังนี้เพื่อไม่ให้ข้อมูลเสียหาย:

✅ วิธีปิดที่ถูกต้อง:
1. กดปุ่มกากบาทปิดหน้าต่างจอดำของเครื่องเสมือน
2. เลือก "Send the shutdown signal"
3. กดปุ่ม OK ระบบจะจัดเก็บข้อมูลและปิดตัวเองลงเรียบร้อย
❌ ข้อห้าม:
• ห้ามเลือก "Power off" เด็ดขาด เพราะเทียบเท่ากับการดึงปลั๊กไฟ อาจทำให้ไฟล์พังจนต้องโหลดใหม่
• ไม่ต้องเลือก "Save the machine state"
6 เช็กลิสต์ของที่ต้องนำมาในวันอบรม
  • ✓ แล็ปท็อปที่ติดตั้ง VirtualBox และนำเข้าเครื่อง Farm Workshop สำเร็จแล้ว
  • ✓ สายชาร์จ / อะแดปเตอร์จ่ายไฟของแล็ปท็อป (แนะนำพกปลั๊กพ่วงมาด้วย)
  • ✓ สมาร์ตโฟน (เปิด Wi-Fi ได้) สำหรับใช้ทดลองเปิดแดชบอร์ดควบคุม
  • ✓ เมาส์แยก (แนะนำ เพื่อความสะดวกในการลากวางบล็อกคำสั่ง)
7 การแก้ไขปัญหาเบื้องต้น (FAQ / Troubleshooting)
❓ หน้าจอดำขึ้นเลข IP เป็น 169.254.x.x หรือไม่มีเลข IP
เกิดจากแล็ปท็อปไม่ได้ต่อ Wi-Fi ก่อนเปิดเครื่องเสมือน หรือการ์ดเน็ตเวิร์กตั้งค่าผิด
วิธีแก้: ปิดเครื่องด้วย Shutdown signal → ต่อ Wi-Fi ของเครื่องหลักให้เรียบร้อย → ไปที่ VirtualBox Settings → Network → ตรวจสอบว่าเลือก Bridged Adapter และเลือกการ์ด Wi-Fi (เช่น en0: Wi-Fi บน Mac) → กด Start ใหม่อีกครั้ง
❓ พิมพ์เลข IP แล้วหน้าเว็บไม่โหลดหรือโหลดค้าง
วิธีแก้:
1. ตรวจสอบว่าพิมพ์ขึ้นต้นด้วย http:// ไม่ใช่ https://
2. ให้ลองเติมพอร์ต :8123 ต่อท้าย เช่น http://192.168.1.50:8123
3. หากแล็ปท็อปเปิด VPN ให้กดปิด (Disconnect) VPN ก่อนใช้งาน
❓ ติดตั้งแล้วเผลอกด Power off เครื่องมีโอกาสพังไหม?
หากกดไปเพียงครั้งเดียวและระบบยังไม่เริ่มเขียนฐานข้อมูล ระบบอาจยังบูตขึ้นได้ แต่หากเปิดแล้วขึ้น Error จอดำค้าง วิธีแก้ที่ดีที่สุดคือ ลบเครื่องเสมือนตัวเดิมออก (Remove only) แล้วทำขั้นตอน Import Appliance... ไฟล์ .ova ใหม่อีกครั้ง
